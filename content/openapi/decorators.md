Mavjud OpenAPI dekoratorlarining barchasi asosiy dekoratorlardan farqlash uchun `Api` prefiksiga ega. Quyida eksport qilinadigan dekoratorlarning to'liq ro'yxati va dekorator qo'llanishi mumkin bo'lgan daraja ko'rsatilgan.

|                           |                     |
| ------------------------- | ------------------- |
| `@ApiBasicAuth()`         | Metod / Controller  |
| `@ApiBearerAuth()`        | Metod / Controller  |
| `@ApiBody()`              | Metod               |
| `@ApiConsumes()`          | Metod / Controller  |
| `@ApiCookieAuth()`        | Metod / Controller  |
| `@ApiExcludeController()` | Controller          |
| `@ApiExcludeEndpoint()`   | Metod               |
| `@ApiExtension()`         | Metod               |
| `@ApiExtraModels()`       | Metod / Controller  |
| `@ApiHeader()`            | Metod / Controller  |
| `@ApiHideProperty()`      | Model               |
| `@ApiOAuth2()`            | Metod / Controller  |
| `@ApiOperation()`         | Metod               |
| `@ApiParam()`             | Metod / Controller  |
| `@ApiProduces()`          | Metod / Controller  |
| `@ApiSchema()`            | Model               |
| `@ApiProperty()`          | Model               |
| `@ApiPropertyOptional()`  | Model               |
| `@ApiQuery()`             | Metod / Controller  |
| `@ApiResponse()`          | Metod / Controller  |
| `@ApiSecurity()`          | Metod / Controller  |
| `@ApiTags()`              | Metod / Controller  |
| `@ApiCallbacks()`         | Metod / Controller  |
